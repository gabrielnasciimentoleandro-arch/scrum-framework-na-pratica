# Guia de entrega na DIO

## Repositório sugerido

`https://github.com/gabrielnasciimentoleandro-arch/scrum-framework-na-pratica`

## Descrição sugerida

Projeto autoral que apresenta o Framework Scrum de forma visual e aplicada, organizando responsabilidades, eventos, artefatos, compromissos, pilares e valores conforme o Scrum Guide 2020. A entrega inclui classificação de conceitos, antipadrões, quiz, diagramas próprios e uma Sprint prática do produto fictício EcoCiclo.

## Texto para entregar

Neste projeto reconstruí de forma autoral o Framework Scrum com base no Scrum Guide 2020. Organizei as responsabilidades do Scrum Team, os cinco eventos, os três artefatos e seus compromissos, além dos pilares e valores. Também diferenciei elementos oficiais de técnicas opcionais e pegadinhas comuns. Para demonstrar a aplicação prática, desenvolvi o caso fictício EcoCiclo, com Meta do Produto, Product Backlog, Sprint Goal, Definition of Done e calendário de uma Sprint de quatro semanas. O repositório contém guia interativo, diagramas, quiz e versões em PDF e DOCX.
